# Decisions

## 2026-07-31 — Isolated Sender identity

Use a distinct application name, bundle identifier, URL scheme, preferences,
support data and logs so the fork can coexist with the original installation.

## 2026-07-31 — Read-only network selection

Discover and bind the selected interface without assigning addresses, changing
routes, disabling Wi-Fi or bonding physical links.

## 2026-08-13 — Explicit Full HD profiles

The iMac 2011 Receiver has a 1920 × 1080 panel and cannot rely on HEVC hardware
decoding. The existing 4K HiDPI preset captures 4096 × 2304 HEVC, so Full HD
30 and Full HD 60 presets were added at 1920 × 1080 and forced to H.264. The
existing 4K profiles remain unchanged.
